- 路径：`F:\我的知识库\vision-wiki\`（Obsidian 直接打开此文件夹即 vault）
- 模式：Karpathy Wiki（raw 原始资料 / wiki LLM 维护知识层 / CLAUDE.md schema）

## 两条死规矩（已写入 CLAUDE.md，不可违反）
1. 交互时一次只问一个问题，像真实对话伙伴，不一次性甩一堆。
2. 输出完整目录后必须等主人说"行"才动手搭建；任何结构级改动都先给方案等确认。

## 内容板块
算法（algorithms）/ 项目（projects）/ 硬件（hardware）/ 系统（systems）四大类。
项目页强制含防遗漏五栏目：关键参数与标定结果、硬件选型 BOM、踩坑与 root cause、客户/产线特殊约定、相关代码/算子。

## 工作流
- Ingest：资料存 raw → 建/更新 wiki 对应页 → 更新 index.md 与 log.md。
- Query：先读 index 找页 → 综合回答 → 有持续价值的存回 synthesis/。
- Lint：扫描矛盾/孤立页/缺失交叉引用，自动修能修的，报告需人工判断的。

## 目标
让小程工作更轻松——做项目前复用已有方案/选型/踩坑，避免重复劳动。

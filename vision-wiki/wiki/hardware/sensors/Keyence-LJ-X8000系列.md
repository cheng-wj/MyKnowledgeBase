# 基恩士 LJ-X8000 系列 — 2D/3D 线激光测量仪

## 一句话定位
在线 3D 检测用的**线激光轮廓传感器**（激光位移/轮廓仪），用光切断法直接输出高度/截面/3D 形状数据；主打"高速、稳定、免开发软件"，用于高度差、间隙、平面度、体积、毛刺凹陷、翘曲等在线 3D 尺寸与外观检测。

## 测量原理（光切断法 / 激光三角测量）
柱面物镜把**蓝色半导体激光（405 nm，2M 类）**扩散成线激光投到工件表面 → 表面漫反射光经**大口径受光镜头**在 **CMOS** 上成像 → 通过检测光斑位置/形状变化算出位移与截面轮廓。
- 相比 2D 面阵相机（如 [[MARS-2442-192X2M-NF]]、[[TS21MCXP12-230M]] 拍灰度图再做算法）：它**直接给高度/3D 数据**，不易受工件颜色、图案、同色凹陷影响，能测宽度/高度/面积/体积/平面度/角度等。

## 核心特性
- **3200 点/轮廓**：新开发高精度 CMOS（5120 万像素级）+ 柱面物镜 + 3 倍测量面积大口径受光镜头；对比旧款 LJ-V7000，**X 轴精度提 4 倍、Z 轴提 3 倍**（轮廓数据间隔最小 2.5 µm，Z 轴直线性 ±0.03% F.S.）。
- **单帧 HDR**：一次拍摄同时测黑色（低反射率）和光泽面（高反射率），高灵敏度大动态范围。
- **稳定测量**：半透明物体专用检测算法（密封材料等）、杂散光抑制（多重/漫反射）、去除死角干扰、去除突出干扰、**双传感头合成补死角**。
- **3D 位置补偿**：区域轮廓检测自动识别工件错位/倾斜并补正，搬送中也能稳定测；自动工件检测（无需外部触发）。
- **免编程 3 步设定**：拍摄设定 → 位置偏移补正 → 检测工具（平面度/间隙/外观等工具图标点选）；也有 **LJ Developer / Pro** 供 C#/C++ 二次开发。

## 控制器 / 系统
- **控制器**：LJ-X8000（标准，2D/3D）、LJ-X8000E、LJ-X8000A（高自由度编程/多台同步）；或接 **XG-X2900LJ** 图像处理控制器（2D/3D 混合）。
- **采样周期**：接 LJ-X 系列探头最高 **16 kHz（63 µs）**（2D）/ 3D 最高 1 kHz；接旧 LJ-V7000 可达 64 kHz。
- **通信**：Ethernet（1000BASE-T，支持巨型帧）、EtherCAT、PROFINET、EtherNet/IP、CC-Link、PLC Link（基恩士 KV / 三菱 / 欧姆龙 / 安川）、RS-232C、USB；支持 FTP/SFTP/VNC。
- 最多接 2 台同型号探头（LJ-X8000A 支持多台同步测量）。
- 配套：探头电缆 CB-B 系列（3/10m，可延长到 5/10/20m）、对齐校正板 OP-89299/89300、ND 滤光片、SD 卡、24V 电源等。

## 典型应用
车体高度差/间隙、制动盘碰痕/OCR、金属加工端面（倒角/C 面）形状、轮胎形状/DOT 代码、电池各面尺寸/平面度/焊接状态、密封材料（半透明）检测、皮带轮角度/R、PCB 封装元件高度等。

## 与面阵相机方案怎么选（经验）
- 要**高度/厚度/平面度/体积/3D 形状/高低差**数值，或工件有同色凹陷、颜色图案干扰 → 优先线激光 3D 传感器（本系列）；
- 只要**2D 外观/字符/缺陷/尺寸**且平面目标 → 面阵相机（[[MARS-2442-192X2M-NF]]、[[TS21MCXP12-230M]]）+ 光源 + 算法更灵活便宜；
- 3D 传感器按视野/量程选探头，注意**基准距离（安装高度）**和探头体积；反光/黑色件靠单帧 HDR + 杂散光抑制。
